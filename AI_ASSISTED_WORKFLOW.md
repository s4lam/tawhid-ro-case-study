# AI-Assisted Workflow

The private `tawhid.ro` project was built with AI-assisted development tools. This document explains that workflow honestly for portfolio review.

## Requirements Planning

I defined the project purpose, audience, constraints, and priorities. AI tools helped turn those goals into implementation plans, checklists, and task breakdowns.

## Prompting

I directed AI tools through prompts, review instructions, and iteration. Prompting was used to clarify implementation goals, generate draft code, review risks, and improve documentation.

## Code Generation Assistance

AI tools helped generate and modify parts of the private project implementation. This included support for frontend structure, content presentation, scripts, configuration review, and debugging.

The generated work still required human review. I did not treat AI output as automatically correct.

## Manual Review

I reviewed changes for project fit, correctness, maintainability, and security risk. Review included checking whether generated output matched the intended content structure and whether uncertain claims or implementation details needed more verification.

## Testing

AI tools helped suggest checks and interpret failures. I remained responsible for running tests, reviewing results, and deciding whether behavior was acceptable.

## Security Review

AI tools helped create security checklists, identify common web risks, and review areas such as secrets, dependencies, XSS, spam protection, headers, privacy, DNS, and deployment access.

Security responsibility remains mine. AI assistance does not replace manual review, account security, patching, monitoring, or incident response.

## Limitations

- AI output can be incomplete, incorrect, or overconfident.
- AI can suggest insecure code if prompts or review are weak.
- AI does not know private deployment state unless it is explicitly inspected.
- AI-generated claims must be verified before publication.
- Religious educational content requires careful human review and responsibility.

## Ownership Statement

AI helped with implementation and review support, but I am responsible for understanding, reviewing, maintaining, and securing the project.
